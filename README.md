# Hareesh — React JS Developer Portfolio

A responsive dark-theme portfolio built with React, Vite and CSS.

## Requirements
- Node.js 18+ (recommended)
- npm
- Git (optional, for GitHub deployment)

## Run locally
```bash
npm install
npm run dev
```
Open the local URL shown by Vite.

## Build for production
```bash
npm run build
npm run preview
```

## Personalise before publishing
1. Open `src/main.jsx`.
2. Replace `Hareesh` and the experience text if needed.
3. Replace the placeholder email `ADD-YOUR-EMAIL@example.com` with your professional email.
4. Replace GitHub and LinkedIn links with your real profile URLs.
5. Replace the three sample project concepts with real projects you have built. Do not present the sample concepts as completed client work.
6. Review the "available for freelance" message and change it if your employment agreement does not permit outside work.

## Deploy with GitHub + Vercel
1. Create a GitHub account at https://github.com/
2. Create a new public repository, e.g. `hareesh-react-portfolio`.
3. Upload the project files (the contents of this folder) to the repository.
4. Visit https://vercel.com/ and sign in using GitHub.
5. Select **Add New → Project**, import `hareesh-react-portfolio`.
6. Vercel should detect Vite automatically. Use:
   - Framework preset: Vite
   - Build command: `npm run build`
   - Output directory: `dist`
7. Click **Deploy**. Vercel will provide a public URL.
8. Every future push to the connected GitHub repository can trigger a new deployment.

## Contact setup
The contact email is intentionally a placeholder. Add your email before publishing so visitors do not click a broken contact link.
